# SEO для PAV IT — що зроблено і що робити далі

## Що змінилось у проєкті
- **Prerender.** `npm run build` тепер створює окремий готовий HTML для кожної сторінки
  (`/`, `/about-us/`, `/services/`, `/contact-us/` та те саме під `/en/`). Пошуковий робот бачить текст
  одразу, без виконання JavaScript. React при відкритті сторінки замінює цей HTML на живий.
- **Унікальні title / description / canonical / hreflang / Open Graph** для кожної сторінки й мови
  (`src/seo/meta.ts` — єдине місце, де їх можна змінити).
- **Бренд двома написаннями:** «PAV IT» і «ПАВ ІТ» — у title, description, JSON-LD (`alternateName`) та футері.
  Українські запити: «створення сайтів», «розробка веб-додатків», «агенція веб-розробки».
- **JSON-LD:** Organization + WebSite (з `alternateName`) на всіх сторінках, BreadcrumbList на внутрішніх.
- **sitemap.xml** генерується під час білду (8 адрес); **robots.txt** — у `public/`.
- Прибрано дубль `<noscript>` (контент тепер у самому HTML).

## ВАЖЛИВО перед заливкою
1. У вашому репозиторії в `index.html` вже є тег `google-site-verification`.
   Мій `index.html` його не містить. Скопіюйте ваш рядок
   `<meta name="google-site-verification" content="...">` зі старого `index.html`
   у новий (місце позначене коментарем у `<head>`), інакше Google може зняти підтвердження власності.
2. **Текст головної живе у WordPress** (ACF «pav-settings»: hero_title, hero_subtitle, about_*).
   Google побачить саме його. Додайте в `hero_subtitle` (uk) фразу на кшталт:
   «PAV IT (ПАВ ІТ) — агенція веб-розробки: створення сайтів і веб-додатків…»,
   а в `hero_title` — слова «розробка сайтів / веб-додатків». Без цього у видимому тексті
   не буде тих слів, за якими вас шукають.
3. Футер: поле `footer_copyright` у WP теж має містити «PAV IT (ПАВ ІТ)».

## Деплой
`git add . && git commit -m "SEO: prerender, meta, sitemap" && git push` — Actions збере й залиє `dist/`.
Після деплою перевірте в браузері:
- https://pav-it.ct.ws/sitemap.xml та /robots.txt (мають бути XML/текст)
- https://pav-it.ct.ws/about-us/ → Ctrl+U: у коді має бути текст сторінки та свій `<title>`
- https://pav-it.ct.ws/en/ → відкривається англійська версія

## Search Console
1. Sitemaps → видаліть старий запис, додайте `sitemap.xml` ще раз.
2. Перевірка URL → вставте кожну з 8 адрес (зі слешем у кінці) → «Перевірити опубліковану URL-адресу» →
   вкладка **HTML** має показувати текст сторінки, а не сторінку-перевірку InfinityFree → «Запит на індексування».
3. Розділ «Проблеми з безпекою» → якщо «Шкідливі завантаження» ще є, після перевірки файлів
   надішліть запит на повторну перевірку.

## Що від коду не залежить
- Безкоштовний піддомен `ct.ws` і захист від ботів InfinityFree (сторінка-перевірка з `?i=1`) можуть
  блокувати індексацію. Якщо у вкладці HTML замість вашого сайту код із `aes.js` — потрібен інший хостинг
  (Vercel / Netlify / Cloudflare Pages) або власний домен.
- Нові сайти індексуються 1–4 тижні; позиції за конкурентними запитами потребують зовнішніх посилань
  (LinkedIn, GitHub, Upwork, Fiverr, каталоги на кшталт Clutch / DOU).

## Логотип (favicon і шапка)
- У шапці сайту тепер знак (мережа з вузлів) + напис «PAV | IT».
- Додано повний набір іконок: `favicon.ico`, `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`
  (у `public/`, підключені в `index.html`). Саме favicon Google показує біля вашого сайту у видачі.
- Google оновлює іконку у видачі не одразу: зазвичай від кількох днів до кількох тижнів.
  Пришвидшити можна, запросивши повторну індексацію головної в Search Console.
- Перевірте, що `https://pav-it.ct.ws/favicon.ico` відкривається (не сторінка-перевірка хостингу).
